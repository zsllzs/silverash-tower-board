# 银灰塔作战板

《明日方舟》主线关卡与干员消耗记录工具。银灰默认编入每一关；可拖动干员，也可在关卡里搜索名字直接添加。点击干员的“技能”可打开 PRTS。

网站：[GitHub Pages](https://zsllzs.github.io/silverash-tower-board/)

## 多人协作

在页面上输入房间名和至少 8 位密码，点击“创建房间”；队友输入相同的房间名和密码，点击“加入房间”；房主无需在线。如果房间还未创建，首次加入会自动建立云端房间。邀请链接只包含房间名，密码需要另外告知。创建或加入后，关卡记录会加密保存到 Supabase 免费数据库，并在同房间的在线页面间同步。通常约 30 秒内刷新，也可以点击“立即同步”。各房间的本机记录分开保存，离开房间会回到本机记录。

共享记录使用密码派生的密钥加密，密码不会写入网址或浏览器存储。关卡完整记录仍以密文保存；为了显示在线成员和每日调整，数据库还保存昵称、操作摘要与时间。密码遗失无法恢复记录。免费项目长期没有活动时可能暂停，请定期用“导出记录”备份。旧版随机房间链接仍可加入，但旧房间没有密码保护或云端持久保存。
